# Sponsorship Outreach Agent — Demo

An interactive demo of an AI agent service for YouTube creators, by **Aqua Ter**.

## What the agent does

1. **Scans the niche** — finds videos in your niche with brand integrations from the last 90 days.
2. **Identifies sponsors** — lists the brands behind those integrations: brands already paying creators your size.
3. **Verifies activity** — drops expired sponsorships and flags misleading clips.
4. **Finds the contact** — locates the partnerships / creator contact for each brand.
5. **Drafts outreach** — writes one personalised email per brand, built around your channel's numbers and the brand's actual campaigns.
6. **Follows up** — one polite follow-up per brand, plus a weekly report (sent / replied / negotiating / closed).

## What you get (one run)

- Verified brand list (10–20 brands) with evidence: which video, when, what deal type
- Verified contacts per brand
- One personalised outreach draft per brand
- Follow-up schedule + weekly report

Pricing is agreed after scope is clear — no fixed price upfront.

## This demo

`index.html` + `styles.css` + `app.js` + `data.js` — a static page, no backend, no tracking.
Pick a niche and a channel size, run the agent, click a brand to preview its outreach draft.

**Sample data:** brands, contacts, and rate ranges in this demo are examples for
demonstration only — not guarantees. In a real run, every brand and contact is
re-verified before anything is sent. Contact addresses shown are common public
patterns (e.g. `partnerships@`); the agent verifies the actual decision-maker.
